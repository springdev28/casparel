# Schoolar

A full-stack student and teacher productivity platform for discovering, reviewing, and organising learning resources — with class management, schedules, Google Classroom sync, and a Google Calendar / iCal feed.

## Run & Operate

| Command | What it does |
|---------|-------------|
| `pnpm --filter @workspace/api-server run dev` | Start the API server (port 8080 in Replit, 5000 locally) |
| `pnpm --filter @workspace/app run dev` | Start the web app (port 23863, proxies `/api` → API server) |
| `pnpm --filter @workspace/mobile run dev` | Start the Expo mobile app |
| `pnpm run typecheck` | Full typecheck across all packages |
| `pnpm run build` | Typecheck + build all packages |
| `pnpm --filter @workspace/api-spec run codegen` | Regenerate API hooks + Zod schemas from OpenAPI spec |
| `pnpm --filter @workspace/db run generate` | Generate a Drizzle migration after schema changes |

Required env: `DATABASE_URL` — PostgreSQL connection string.
Optional: `PORT`, `BASE_PATH`, `API_URL`, `SESSION_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.

## Stack

- **Monorepo**: pnpm workspaces, Node.js 24, TypeScript 5.9
- **API**: Express 5, Drizzle ORM, PostgreSQL
- **Validation**: Zod (`zod/v4`), `drizzle-zod`
- **API contract**: Single OpenAPI spec (`lib/api-spec/openapi.yaml`); hooks and schemas are generated by Orval
- **Web**: React 19, Vite 7, Tailwind CSS v4, TanStack Query, Wouter
- **Mobile**: Expo (React Native), Expo Router
- **Design system**: `@workspace/edu-ds` — shared Radix + shadcn components and design tokens
- **Auth**: Custom HMAC-SHA256 Bearer token, stored as `schoolar_token` in localStorage

## Architecture decisions

- **Generated API layer**: All client-server contracts flow through `openapi.yaml` → Orval codegen. Adding a route means editing the spec first, then running codegen — never hand-writing hooks.
- **Migrations, never push**: All DB schema changes go through Drizzle migration files (`lib/db/migrations/`). The API server runs `runMigrations()` on every startup. `drizzle push` is banned in production.
- **Timestamp mode "string"**: Drizzle timestamp columns use `mode: "string"` so pg's Date objects don't break Zod string schemas at runtime.
- **Zod v4 compat path**: The workspace ships `zod@3`; generated files import from `'zod/v4'` (the compat export), not `'zod'`.
- **Single auth token key**: `schoolar_token` in localStorage — used identically in the web app and mobile app. Do not rename.

## Product

- **Resources**: Public browsable library of learning resources with ratings, reviews, and AI-powered discovery. Teachers can add and manage resources; students can save them to lists.
- **Classes**: Teachers create classes and invite students. Class resources can be assigned and shared as lists.
- **Lists**: Users build personal reading lists; teachers can share lists with their classes.
- **Schedule**: Personal schedule blocks with optional resource attachments. Google Calendar sync (OAuth) and iCal subscription feed.
- **Study sessions**: Collaborative sessions with meeting links, RSVP, and class association.
- **Google Classroom**: OAuth-based sync — import courses as classes, push resources to the Classroom stream.
- **Profiles**: User profiles with bio, subjects, grade/department, avatar, timezone, and website.
- **AI features**: Deep Research (source review), AI resource discovery, live web search.

## Gotchas

- **Port conflicts on restart**: If a workflow fails with `EADDRINUSE`, run `lsof -ti :PORT | xargs kill -9` to clear the stale process.
- **Shell script env vars**: In `scripts/run-schoolar.sh`, always `export VAR=value` before `exec`. Inline assignments on the `exec` line (`exec VAR=x cmd`) are not portable and cause `exec: VAR=x: not found`.
- **Migration gap**: The DB was originally bootstrapped with `drizzle push`, so `__drizzle_migrations` may not exist on older environments. After any merge that adds schema columns, verify the migration ran — otherwise login will crash with "column does not exist".
- **Workspace symlink**: `@workspace/edu-ds` symlinks to `artifacts/schoolar-edu`. If the symlink breaks after a directory rename, run `pnpm install` from the repo root to re-link.
- **Codegen after OpenAPI changes**: If generated hooks appear `undefined` at runtime after an OpenAPI spec change, the codegen wasn't run. Run `pnpm --filter @workspace/api-spec run codegen` and clear `artifacts/app/node_modules/.vite`.
